What is deliberately not on this page

Groundwork’s configuration table also holds the Resend API key, the agent dispatch secret and the GoHighLevel credentials. That table is unreadable from the browser on purpose, and no admin session can read it — so those values are not shown, not editable, and not hidden behind a permission. Provider setup lives on Integrations.
